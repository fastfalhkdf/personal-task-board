# 项目启动流程

> 本机环境已就绪、只想把服务跑起来 → 见《直接启动》（一条命令）。

## 1. 获取代码

```bash
git clone https://gitcode.com/hxqx/personal-task-board.git
cd personal-task-board
```

（GitHub 开源镜像任选：`git clone https://github.com/fastfalhkdf/personal-task-board.git`）

## 2. 建环境、装依赖（需 Python 3.11）

```bash
py -3.11 -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt -r requirements-dev.txt
```

## 3. 配置

```bash
copy .env.example .env
```

- 只用看板、跑测试：不用改任何内容；
- 要用 Agent 对话：在 `.env` 里填 `SILICONFLOW_API_KEY=你的key`。

## 4. 启动

```bash
.venv/Scripts/python -m uvicorn app.main:app --port 8000
```

首次启动自动建库并注入演示数据，终端出现 `Uvicorn running on http://127.0.0.1:8000` 即成功。

> 要让局域网其他人访问：加 `--host 0.0.0.0`，见《局域网部署说明》。

## 5. 验证

浏览器打开 <http://localhost:8000>，用 `demo@tasks.dev / demo1234` 登录，看到四列看板即启动完成。

新用户（组员）在登录卡点「还没有账号？注册」，填昵称 + 邮箱 + 密码（≥8 位），注册成功自动登录。

## 6. 跑测试（可选）

```bash
.venv/Scripts/python -m pytest -q    # 预期 39 passed
```

## 7. 停止

终端 `Ctrl+C`。
